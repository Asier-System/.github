# Welcome to Asier System!

Let's be honest, we all have that shitty laptop that suffers with the lightest piece of software.
Many people would like to change to a more efficient OS, like Linux. 
But, what if you don't want to do so, and stay in your OS? Well, Asier System's for you! 
I came with this problem 2 years ago, and I brainstormed for a long long time. 
The result of this comically large brainstorm is Asier System! Asier system is a Web OS available as an Electron 
(Might sound heavy and unneficient, but it actually works good) or just a website! [URL] 
It works with ASPL, a basic syntax programming language made specifically to meet the needs of Asier System.
